# Design System & Theme Selection

## Selected Theme: Option 4 — Warm Ivory, Deep Atlas Navy & Regal Gold

### Theme Tokens

#### Light Theme (`data-theme="light"`)
| Token | Hex Value | Semantic Role |
|---|---|---|
| Background | `#FAF8F5` | Main canvas background |
| Surface | `#FFFFFF` | Cards, panels, elevated elements |
| Secondary Surface | `#F4EFE6` | Sidebars, subtle containers, table headers |
| Primary Text | `#0A1128` | Main headings, primary copy |
| Secondary Text | `#475569` | Subtitles, metadata, captions |
| Accent | `#C48A1E` | Highlights, badges, active indicators |
| CTA | `#0A1128` | Primary action buttons |

#### Dark Theme (`data-theme="dark"`)
| Token | Hex Value | Semantic Role |
|---|---|---|
| Background | `#0F0F0F` | Deep dark canvas background |
| Surface | `#181818` | Elevated cards, modals, containers |
| Secondary Surface | `#212121` | Toolbars, subtle groupings |
| Primary Text | `#F5F5F5` | Bright readability on dark |
| Secondary Text | `#A3A3A3` | Dimmed metadata, borders |
| Accent | `#14B8A6` | Electric teal accents & highlights |
| CTA | `#14B8A6` | Primary action buttons in dark mode |
